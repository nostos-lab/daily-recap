# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its Code of Conduct.

The full text — including standards, scope, enforcement responsibilities, and the enforcement ladder — is published by the Contributor Covenant organization:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project (issues, pull requests, discussions, or any other contribution), you agree to abide by that document.

## Reporting

Reports of unacceptable behavior may be sent privately to the project maintainers at:

- **admin@nostoslab.space**

All reports will be reviewed and investigated promptly and fairly. The maintainers are obligated to respect the privacy and safety of the reporter.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1, available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
